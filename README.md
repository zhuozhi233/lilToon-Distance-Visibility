# lilToon 距离显示

这个工具只修改用户明确选择的材质，不会批量修改工程中的所有 lilToon 材质。

## 使用方法

1. 在 Project 窗口中选中一个或多个 lilToon 材质。
2. 在材质球上右键选择 `添加距离显示`。
3. 在材质 Inspector 的“距离显示”区域打开“启用距离显示”，再设置需要的距离限制。
4. 要恢复时，在材质球上右键选择 `移除距离显示`。

右键菜单会同时显示“添加距离显示”和“移除距离显示”，并根据当前材质状态禁用不适用的操作。

## LyumaShader Extended 兼容

同时安装 LyumaShader Extended 时，可以先添加距离显示，也可以先将材质转换为 Waifu2d。两个工具会自动生成同时包含距离显示与 2D 功能的组合 Shader。

- 从组合材质移除距离显示时，会保留 Waifu2d。
- 从组合材质恢复为 3D 时，会保留距离显示。
- Waifu2d 配置工具会将距离显示识别为已适配功能，不需要启用第三方变体兼容选项。

## 距离限制

- “启用距离显示”是总开关，默认关闭；关闭时材质不执行距离隐藏。
- 同时启用近端和远端限制：小于近端距离或大于远端距离时隐藏，只在中间显示。
- 只启用远端限制：近处显示，超过远端距离后隐藏。
- 只启用近端限制：远处显示，靠近时隐藏。
- 两项都关闭：始终显示。

近端和远端均可分别设置过渡距离。过渡采用抖动淡入淡出，以便保留原材质的不透明、裁剪或透明渲染模式。

默认按每个像素到相机的距离计算。启用“使用网格中心（对象原点）”后，改为使用对象的 Transform 原点计算，因此整个网格会统一出现或消失，并且同一个材质仍可供多个对象共用。

首次转换材质时，工具会根据当前安装的 lilToon 版本在本 Package 的 `Generated/lilToon` 下生成私有 Shader。不要手工编辑该目录；需要重建时使用菜单 `工具 > lilToon 距离显示 > 重新生成 Shader`。
